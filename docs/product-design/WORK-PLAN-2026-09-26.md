# Work plan, 26.9.2026: stronger reaction to sound, a lighter control window

**The owner's feedback:** the scene menu and the grouping work well. But the reaction to sound felt stronger in the previous version, and there are still too many knobs.

**Inputs:**
- [REACTION-DESIGN.md](REACTION-DESIGN.md): the reaction model
- [CONTROL-MAP.md](CONTROL-MAP.md): where every control lives
- [REACTIVITY-FORENSICS.md](REACTIVITY-FORENSICS.md): old vs new, measured (in progress)
- [../REFERENCE-ZWOBOT-SHOWCASE.md](../REFERENCE-ZWOBOT-SHOWCASE.md): the owner's analysis of the Zwobot showcase

## Conclusions from the research

1. **Why the reaction faded.** The previous version:
   - reseeded every scene on every kick, so each kick left a lasting change
   - let the bass drive the speed of 10 scenes

   The redesign removed both to stop the jumps. What remained is a hit that disappears within 2-3 frames (a 53 ms half-life), a kick scaled down to about 0.3, and an image that looks almost the same in silence and in music.
2. **The Zwobot lesson:** "dark in silence, an event on the hit, not on every hit". So contrast matters more than amplitude.
3. **The control load:** 77 clickable controls sit on one screen, and 7 different controls answer "how much does it react".

## Decisions where the documents disagree

- **The fifth knob (`macro5`)** is called **REACT** from now on: 0 = ignores the music, 50 = as designed, 100 = wild. The ID is unchanged, so MIDI maps survive.
- **One row: STILL · BREATHE · PULSE · PUNCH.**
  - STILL = the old CALM.
  - The character is an engine setting (`/v2/style`): how hits are selected, the envelope lengths, how dark silence gets, and Push.
  - It does **not** switch the LISTEN toggles.
- **LISTEN (kick / snare / hat / bass / level)** becomes lamps that flash on each hit, on PLAY. Clicking a lamp mutes that channel.
- **Moved to the expert tab (EDIT › REACT):** Reactivity, Softness and Push, as trims.
- **Moved to SETUP:** Hit Sens, Trim and Response.
- **LOOK** becomes one choice (Clean / Film / Worn / Broken / Print / Data) plus AMOUNT. The individual knobs live in EDIT › LOOK.
- **DROP** is a new action (a button plus MIDI) and is also detected automatically.

## Order of work

**A. Engine: reaction (priority 1, what the owner feels)**
1. `Signals`: accent / tick / drop events and a `ReactionState`.
2. `Reaction.h/.cpp`, the ReactionShaper:
   - auto-ranged body / energy / air
   - breathing
   - accent selection with a governor
   - REST
   - tension and DROP (automatic and manual)
   - scars
   - three character tables
3. `SceneClock::kick` (the time kick), plus the MainComponent wiring: REACT = macro 5, `/v2/style`, `/v2/trigger drop`, status fields.
4. `Modulation`:
   - `react.*` sources
   - split gains (continuous = contAmount, hits = hitAmount)
   - an envelope hold
   - styled envelopes
   - trigger `scale`
5. `PresetV2`: parse the new fields.
6. `LookPass`:
   - exposure (the rest floor and the drop bloom)
   - breath zoom
   - dust from scars
   - Flash / SHOTS on accents
7. Auto-cut on accents.
8. The generator and all 16 scenes, following the table in REACTION-DESIGN §5.
9. Measure (the forensics harness): hit contrast and rest vs play, old vs new.

**B. Plug-in: the control model**
1. New parameters: `reactStyle`, `drop`, `lookPreset`, `lookAmount`. Send `/v2/style`.
2. Elect the lead automatically (one instance sends controls), and set the role from the track name.
3. Moments: click an empty slot to save; they also remember the look and the style.

**C. Plug-in: a new UI**
- **PLAY** 760x480:
  - a 4x4 scene grid with cue / GO
  - the REACT row with its lamps
  - STYLE (colour, look, amount)
  - image
  - moments
  - 8 knobs
  - HIT / DROP
  - an info line
- **EDIT:** a drawer (1180x480) with six tabs: LOOK, COLOUR, REACT, MOTION, MEDIA, SETUP.
- **SOURCE** 360x240 for instances that do not lead.
- **The colour language:** warm black, bone text, red only for what is live, amber for what is waiting.

**D. Verification and delivery**
- The harness self-test and screenshots of every state
- cue / GO end to end with the engine
- the freeze test (Speed 0 = still, even with hits)
- install the VST3
- update USAGE / QUICKSTART-HE
