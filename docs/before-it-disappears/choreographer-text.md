# Before It Disappears: the choreographer's text

Written by the choreographer of the piece (name to be added). Kept verbatim, including line breaks: the
line breaks are part of the text, since the lines grow shorter toward the end.

---

We think memories fade.

They don't.

They wait.

Quietly.

Like silence.

Movement disappears before we can hold it.

Life keeps moving.

Silence comes and goes.

Every moment is already leaving
while we are still living inside it.

We reach for it anyway.

We slow it down.

We replay it.

We give it names.

But the moment itself never returns.

Only the memory does.

A memory lives inside a frame.

It keeps the outline,
never the whole story.

The edges begin to soften.

The colors slowly change.

The story is rewritten
every time it is remembered.

Perhaps we don't remember the past at all.

Perhaps we remember
the last time
we remembered it.

And then,
something changes.

A memory reaches
the edge of itself.

Beyond that,

it no longer recalls.

It creates.

Maybe that is why
the oldest memories
often feel the clearest.

Not because they remained untouched,

but because
they have been rewritten
by every version of ourselves
that has carried them.

Memory is a cloud.

Always changing.

Always drifting.

Suspended between presence
and absence.

It follows us quietly,

settling in places
we never expect.

A voice.

A scent.

A familiar light.

With time,
every memory becomes
the shadow of itself.

Sometimes that shadow
feels like paradise.

Sometimes it feels
like hell.

Yet we keep returning to it,
hoping to find the moment
exactly as we left it.

But nothing stays still.

Not movement.

Not silence.

Not us.

And maybe,
every time we remember,
we leave a part of ourselves behind.

Until one day,
we no longer carry the memory.

The memory carries us.

Maybe memory was never meant
to preserve what disappeared.

Maybe memory exists
to remind us

that even what is gone

can still leave a shape
inside us.

Maybe memory
is not what survives us.

Maybe memory
is what transforms us.

It lingers
long after the moment
has disappeared.

Until we can no longer tell

where the moment ends,

and where we begin.

Perhaps that was always
the nature of memory—

not to preserve,

but to transform.

Not a place
we return to.

Not something
we carry.

Only a mark.

The quiet mark

left

by everything

that ever

moved us.
